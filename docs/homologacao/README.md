# Central de Testes (homologação)

`central-testes.html` é a página publicada da Central de Testes: links dos sistemas, roteiro de testes,
**Atualizações do sistema** (cada entrega com o que mudou e como validar, marcada como Validado ou Precisa ajuste)
e "Pedir alteração" para todas as frentes (site, Internet Banking, Banqueiro, integração Bradesco e produção), com anexos. As marcações e os ajustes ficam no armazenamento da página publicada, não neste arquivo.

A cada entrega, acrescente a nova atualização no topo da lista `ATUALIZACOES` e publique de novo a página.
Quando todas estiverem validadas, a versão está pronta para produção (veja `docs/PRODUCAO.md`).
