Solicitar acesso à API
Exemplo
# Criar cobrança PIX (exemplo ilustrativo)
curl -X POST $BASE_URL/v1/pix/cobrancas \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "valor": 99.90,
    "vencimento": "2026-10-10",
    "referencia": "fatura-20841"
  }'
// Criar cobrança PIX (exemplo ilustrativo)
const res = await fetch(`${BASE_URL}/v1/pix/cobrancas`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${TOKEN}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    valor: 99.90,
    vencimento: "2026-10-10",
    referencia: "fatura-20841"
  })
});
const { qrcode, copiaecola } = await res.json();

Início / Ajuda
Central de ajuda

Como podemos ajudar?

Dúvidas frequentes

Perguntas que sempre aparecem.

Nenhuma pergunta encontrada. Fale com a nossa equipe.

Quem pode abrir uma conta PAY AX?

Empresas com CNPJ ativo. Nosso foco inicial são provedores de internet e negócios com cobrança recorrente.

Preciso trocar de sistema para usar a PAY AX?

Não. Se você usa o IXC Provedor, a PAY AX se conecta à sua carteira de cobrança e você continua no sistema que já conhece.

Como funciona a baixa automática no IXC?

Quando o cliente paga por PIX ou boleto, a PAY AX identifica a fatura e envia a confirmação ao IXC, que registra a baixa e libera o acesso do cliente.

Como acesso minha conta?

Pelo botão "Acessar minha conta", no topo do site, ou pelo app PAY AX. Nunca pedimos sua senha por telefone, e-mail ou WhatsApp.

Consigo integrar com outro sistema?

Sim. A PAY AX oferece API para integrar cobranças, pagamentos e consultas ao sistema que a sua empresa já usa.

Quais documentos preciso para abrir a conta?

Cartão CNPJ, contrato social ou última alteração, e documentos dos sócios. A lista completa está na página Abra sua conta.

Quanto tempo leva para começar?

Depois da análise de cadastro e da abertura da conta, nossa equipe acompanha a configuração da integração até a primeira cobrança.
